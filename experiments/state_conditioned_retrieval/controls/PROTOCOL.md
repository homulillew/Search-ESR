# S1 controls

Twelve cases are frozen before Query Writer calls. `S_noise` contains three true facts quoted from the same prior observation as S3. They are incidental to the current target Gap and omit candidate identity and the relation answer. Their whitespace word count is kept near S3; ratios are recorded in the control bank. `S_history` provides the complete prior W text and no structured S3 Claims. It may carry extra information present in that original W. Both controls use the exact S1 writer prompt, model, and retriever.

Compare each control with its same-cell S0 and S3. The raw-history token cost is estimated from provider-reported prompt tokens and compared with S3. Noise support and reviewer relevance judgments are frozen in `noise/BANK.json`; the raw W hash is frozen in `raw_history/BANK.json`.
