# S1: concurrently sampled appended versus resolved cards

All 13 R1 checkpoints are used in historical order. B exactly reconstructs prior R1 request: original prefix, unchanged historical Broad Plan card, and frozen Qualification Card. C starts from the identical original prefix and appends just one reviewer-resolved control card. Both use the same DeepSeek model and Search/Find/Open tool schema, one response, no tool execution. B/C order alternates by case index: B then C for even zero-based indices, C then B for odd. Each cell-arm is sampled once; zero retries and no repairs.

The reviewer used only the original question, current prefix, frozen R1 annotation and visible D/W handles to add a required source type and write a concise verification gap. The promotion mapping is mechanical: original `no_target`/`hypothesis_only` → `none`; original `inspectable` → reviewed candidate D/W. C does not restate an unpromoted D# and has no status label or Broad Plan. The concurrent B/C contrast estimates the *combined* effect of replacing two cards with one gap-centered projection. Candidate mention salience alone requires the contingent S1b ablation.

The primary outcome is per-call and per-cell Gap Action Alignment from query, Find arguments or Open window against the frozen verification gap. Preserve first call, mixed batches, repeated supported facts, candidate inspection, promoted target utilization and Search query specificity separately. No source/evidence yield is observed at one step. Historical P1 Broad Plan and R1 Qualification responses are descriptive A references only.
