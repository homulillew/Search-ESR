# Frozen hypotheses

- H1: DeepSeek can identify substantive Claim support without promoting candidate anchors, generic background or adjacent relations. Primary priority is precision and false promotion, not aggregate role accuracy.
- H2: S1 can localize actual support scope without expanding a component to a whole Parent or corrupting relation/object/time/branch.
- H3: Typed S1 reduces false promotion relative to binary S0; when both are near zero (<=5%) no strict improvement is required. Equality alone does not establish a benefit from complexity.
- H4 (conditional E2): Model typed support approaches Gold typed support in faithful residualization. D3 ceiling separates residualizer capacity from assignment/interface errors.

No hypothesis predicts that more state fields, less Search or more Find is desirable. All are currently untested in this experiment; no new model calls have occurred. Repeated historical natural cells and task-specific examples limit external generalization.
