# Offline annotation and selection rules (before acquired-state review)

Archive all QCH first and commit. Then construct review packets from the actual
Writer transitions and raw observed windows only. The reviewer sees no gold
answer, hidden corpus audit or future continuation beyond each state's prefix.
A later state's Claims may be reviewed in its own prefix, never backfilled into
an earlier state. Provenance audit uses only each admission's own observation.

Mark each admitted Claim supported / unsupported / ambiguous, with the exact
observation hash and reason. Any state containing an unsupported material Claim
is ineligible for the clean primary bank. Do not remove the Claim from that
state or invent a replacement. Keep excluded states and reasons in the archive.
Direct source-relative support is distinct from source credibility/global truth.

For each question enumerate its explicit required relations in evaluator-only
natural language. For each selected state identify covered, partial, open and
contradicted relations from Claims; H supplies a candidate but cannot cover a
relation. Keep valid-gap sets broad enough to accept any useful local unknown,
not exact researcher wording. One oracle issue is a local diagnostic example.
Record No-H, weak/strong H, stale/contradicted and true one-gap status.

Selection uses no Need outputs. Per development qid choose up to4 distinct safe
unresolved states: initial; earliest actual update; first later H-bearing state;
latest safe unresolved state. If categories collide, fill by evenly spaced
remaining chronological states. Per confirmation qid choose up to3: initial,
early H-bearing (otherwise earliest updated), latest safe unresolved. Include
all genuine one-gap states as a separately reported stress subset if not already
selected. If rare, report shortage; no synthetic coverage or H. Fully covered
states are archived for later closure work and excluded from ACT primary.

Target dev>=4 qids, confirmation>=24 states and>=8 disjoint new qids. Six and ten
qid acquisitions provide natural-failure margin; no later qid replacements based
on Need performance. A qid with failed acquisition can retain its real initial
state, but cannot supply invented intermediate/late states.

Derive up to12 coverage pairs per split from supported actual Claim additions.
A is a real PRE; B adds exactly one actual Claim and holds Q/H fixed. Mark B as
controlled projection, never natural primary. g is the specific material relation
fully covered by that Claim, not an entire partially covered conjunction. Pick
chronologically, balanced across qids, before Need calls. Prefer at least8 pairs
if material permits; report actual denominator. No newly written Claim/candidate.
H-removal diagnostics may reuse actual H-bearing states, all other input fixed.
Report exact-g activation, valid activation, retirement, B validity separately.

Semantic rubric: relevant, unresolved, grounded, independently answerable,
actionable. Whole-candidate fit and multi-attribute season conjunctions are W.
Entity/time qualifiers necessary to specify one relation are allowed. An ordinary
attribute question about a provisional candidate need not assert candidate=answer;
an asserted unobserved event/binding does. Missing output is unassessable, not a
semantic error. Report ITT and conditional validity separately. Append-only
corrections preserve original-label results and sensitivity.
