# 局部信息支撑测试：冻结文档的旧新工具对照

## 目标与边界

本阶段只测试 Search–Open 能否给模型提供适量、相关、可理解、可继续读取的信息。不要求完成 BC+ 多跳题、解决 gap、纠偏或决定提交。测试没有重新检索，固定文档以排除召回差异。

20 个手工样本包括 11 个正向回归需求、1 个不匹配/信息不足控制、8 个未用于窗口调优的新需求。它们来自 9 篇文档；同文档多个问题不独立，且不是随机评测集。19 个正向需求各标注一处支持原文，只用于离线测量，不发送模型。没有针对这批样本修改线上定位规则。

旧方案提供前 1600 字符和 get_document；新方案提供当前 400-token 原文窗口和 Open。模型已收到初始观察，可继续读取最多两次，再交接实际观察到的信息、引用与局限。明确告知没有新的 Search。两组工具默认读取预算不同，因此比较实际信息量和成本，不声称严格等 token 消融。

首次试运行因历史 Search 调用与只读 schema 不一致而出现无效搜索请求，已单独保留，不纳入本轮。修订协议后的 40 次会话全部完成，工具错误为零。

## 结果

| 指标 | 旧前缀＋分页 | 当前窗口＋Open |
| --- | ---: | ---: |
| 正向样本首次显示预标注片段 | 13/19 | 16/19 |
| 8 个新增需求首次显示预标注片段 | 6/8 | 8/8 |
| 最多两次自主读取后显示预标注片段 | 15/19 | 16/19 |
| 实际继续读取调用 | 3 | 1 |
| 工具错误 | 0 | 0 |
| 无新增字符的成功读取 | 0 | 0 |
| 首次观察 payload tokens（本地估算） | 9,505 | 12,015 |
| 全部观察 payload tokens（本地估算） | 14,422 | 13,098 |
| API 报告总 tokens | 37,039 | 28,519 |
| 交接中无效窗口引用的会话 | 不适用 | 0 |

新方案首次 payload 约增加 26.4%，原因包括元信息和字符/token 预算差异。计入继续读取后，返回 payload 约减少 9.2%。API 总量也较低，但受模型输出长度和独立采样影响，不作为稳定收益结论。payload 指完整序列化观察对象，不含提示词；采用本地 embedding tokenizer 估算，不等同于 API tokenizer。

“预标注片段可见”是范围检查，不是语义支持率。local_08 的新窗口提供了同一事件的另一处描述，却没有包含所标注的原段落，自动统计漏计这份支持。我们保留原标注结果，并单独人工说明，没有事后替换标注使分数提高。

离线预设一次展开可见片段数为旧 17/19、新 18/19，但旧侧只探测从文首读 8000 字符，新侧探测三个方向取任一可达。这是能力诊断而非公平的单次动作成功率，不用作主要优劣指标。

## 可观察的信息收益

- local_09：Riise 任意球描述在正文后部，新 Search 直接展示；旧前缀只含比赛概况。
- local_14：新窗口直接展示 What-a-Mess 的正式姓名，旧侧需要一次读取。
- local_18：新窗口包含决赛对手 Anh Le；旧前缀在其他选手出局附近结束，模型错误推断 Patty Till 为最后对手。工具有助于提供完整局部关系，但模型误读也需单独记录。
- local_06：新初始窗口已经包含戏剧出道年份，但缺少人物别名。一次 around 恢复文首身份，模型随后能交接所见信息。这里 Open 起到补充上下文的作用，而非搜索另一个 gap。

## 尚存局部限制

local_01 的标题是 Peter Nzioki，query 使用 Peter King。初始窗口 [458,2044) 没有文首别名关系，模型将其误认为不同人物。保留标题仍不足以保证查询实体与文档主体可对应。角色表也在窗口之后。它提供了“出演过这部电影”的部分信息，但不能视为完整角色证据。

local_05 两组都只展示出演电影的概述，未给具体角色。按本阶段目标，这应记录为部分支撑，不要求工具自动解决全部缺失信息。

local_12 原文只有标题、占位符和导航。模型仍可能把标题暗示理解为比赛事实，并混淆页面日期与事件日期。工具应保留出处与局限，不能把“返回了原文”计为事实已核实。本例不计为通过，也不要求本阶段强制生成 gap。

## 当前判断

这套工具在本批样本中提供了更多直接可见的相关原文，读取次数没有增加，引用与接口运行正常。它可以保留为后续研究的固定信息接口基线，但这些便利样本不足以证明一般场景稳定改善。

暂不继续叠加定位、gap 或研究状态模块。需要保留的局部待办是别名/主体上下文、表格关系和元信息开销；它们作为后续节点回归项，不要求当前工具自动完成整条证据链。
