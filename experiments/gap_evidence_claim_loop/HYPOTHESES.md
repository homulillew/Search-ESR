# Frozen hypotheses

- H1: Gap conditioning lowers true but Gap-irrelevant Finding uptake from one W.
- H2: Existing committed Claims lower duplicate Finding generation beyond Gap
  conditioning, if duplicates are present at baseline.
- H3: A Gap can also induce unsupported answer completion; direct W support is
  therefore an independent requirement.
- H4: An independent verifier can block incidental, partial and overbroad
  Findings before minimal Claim commit.
- H5: If F1 and F2 pass, a compact single-Gap loop can improve useful evidence
  and Gap resolution without planned Claims or hard tool masks.
