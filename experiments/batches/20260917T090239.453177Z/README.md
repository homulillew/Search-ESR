## 值得优先分析的现象

- 311：候选锁定及重复 query；最终将冲突归因于题目。
- 546：在关键赛事条件仍不匹配时主动结束，说明停止机制还必须考虑答案可靠性。
- 324：预算结束后仍输出搜索意图，文本工具指令未被执行。
- 776：预算结束后长篇继续猜测，最终弃答。
- 1094：搜索中把任意球执行额外限定为进球，后续围绕猜测比赛展开。
- 517：唯一主动阅读文档的题，答案实体正确；不能从 6 题的相关性推断 open 带来因果收益。

5/6 题未调用 get_document；3/6 题预算强制结束。这些计数只描述行为，还需逐条检查搜索片段是否已包含关键证据，以及何时开始偏离。
