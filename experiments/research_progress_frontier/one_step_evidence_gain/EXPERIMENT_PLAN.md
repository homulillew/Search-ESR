# Stage D: one real step and triggered Verify

The case list is the eight-cell `action_routing/stage_d_preselection.json` frozen before any Stage C model response. This stage executes the first valid C-B tool call for each case. Thus V0 is the already sampled free Actor, with no new Actor draw or selection on success. The nominal two cases per Search/Find/Open/Verify are retained even when V0 chooses a different action. Only the first call is executed, and no resulting observation is fed back to an Actor.

Each retrieval cell restores exact D#/W# handles from the historical v3a prefix and uses the existing Orthogonal Search, Find and Open backend. Search is Orthogonal: already discovered documents cannot gain a new local preview. A separate restored tool session is used per cell. All tool calls and results, including failures, are recorded verbatim. One selected C-B response (`C_location_546_results`) contains two Find calls; the frozen one-step rule executes its first call only, retains the second in the Stage C record, and does not substitute it after seeing the first result.

The closure comparison uses two frozen claims. V0 can choose any tool; it invokes the semantic verifier only if the frozen C-B action is Verify. V1 bypasses choice and calls the same DeepSeek verifier on the exact prior W excerpt. Both arms use the same claim and excerpt and make no corpus call for Verify. The two V1 calls and any V0 Verify are distinct requests; no outcome is reused or repaired. The order is V0 result followed by V1 for each closure case.

The reviewer grades a new retrieval observation against only the pre-action ActiveGap and previous W text. `source_compatible`, `useful_evidence`, `gap_effect`, and a short reason are recorded per executed retrieval. Verify is evaluated for correct local closure separately; it is not counted as retrieval evidence. Find records the exact gap, D, query, window and yield. The source-compatibility and yield denominators are actual Search/Find/Open executions, with action type breakdown. Correlated cases from qid 546/1094 are not independent cohorts.

The study tests conditional links, not final question accuracy. The original full multi-hop question may remain unresolved after a locally useful action. A future short rollout is a recommendation only if all four stages show a usable signal; this branch executes no rollout.
