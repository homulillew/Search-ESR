# Frozen semantic review rubric

All evaluators see Original Question. Truth and source audits never enter production requests.

## G1

Closure: compare resolved to frozen primary status, separately q435 strict sensitivity. Premature denominator=open; missed denominator=resolved; invalid is separate and also wrong in intention-to-treat accuracy. Residual labels: complete (all material uncertainty retained), precise (no unnecessary demand), goal_anchored, unsupported_join, solved_item_repetition, new_goal_drift. A name from a partial match cannot establish target identity. An unresolved request for checking a real original clue is not a new goal, even when overly cautious. No outside knowledge supplies missing birth zodiac, dates or identity links. Report resolved/hypothesis-only/unsupported-join/stale-gap cohorts. Paired monotonicity checks whether newly verified requirements disappear, without demanding identical wording.

## G2/G4 decision review

Mask arm and residual/gap treatment metadata; expose original Q, current claim state/hypothesis, frozen gold residual, Actor decision/gap/actions and available workspace. Label residual_reducing, already_solved, goal_drift, hypothesis_overcommit, unnecessary_bridge, reasonable_direct_attack, actionable, stop_correct. Hypothesis-guided direct search is valid exploration; a candidate name in a query alone is not overcommit. Repeating a solved fact with no new discrimination is already_solved, not useful verification. A stop is correct only if original Q is supported by current claims. For resolved states any further research is over-research. A gap mixing solved and useful components may be residual-reducing with a solved-component warning; separate whole-gap failure from partial repetition.

## G3/G4/G5 real progress

Mask arm; packet contains original Q, claims before decision, gold residual rubric, Actor gap and exact real observations. Direct Progress supplies a NEW supported relation or constraint needed by Original Question. Decision Progress supplies a NEW plausible candidate, discriminative constraint or verified exclusion that materially changes the next reasonable research decision. Reviewer records the exact belief update and how it changes that decision. Topic relevance, repetition, a rank hit, or an interesting entity fact alone is No Progress. If both direct and decision evidence exist, record both; Any is their union. Already-resolved cells have no remaining progress to gain. Failures and stops stay in all-decision denominators; additionally report open/action-only denominators. Tool calls per progress uses actual calls divided by decisions with Any Progress. Primary source membership plus actual observed supporting text is required for primary progress; new sufficient sources are sensitivity only.

## State update

For every added claim: entailment by current Observation (or clearly identified existing claims for an explicit task identification), atomicity (one independently checkable proposition), unsupported_join, candidate_overpromotion, incidental_admission. A date in page metadata is not an event date. A true compound sentence can be non-atomic without being false. Each online claim retains exact current W provenance automatically, even if unsupported; do not remove it afterward. Hypothesis set may be provisional; clear is warranted on a material contradiction. A rejected candidate retained in next actions is path lock. Unsupported incumbent claims are not secretly cleaned.

## Loop outcomes and costs

Goal resolution means claims independently support Original Question within three decisions; not merely a correct candidate string or a locally solved Gap. Correct stop=resolved and stopped; premature=stop while original residual nonempty; late=action after resolution. Record unsupported state contamination separately from underlying source evidence. Report per-arm qid outcomes, tool costs, API calls, tokens/cache, no-progress, repeated normalized query or identical Find/Open path, Search/Find/Open mix, Search rank of frozen sufficient sources and actual useful Find windows. No strong inference from zero or sparse events.
