# 固定观察的阅读约定对照：预设方案

本实验检验一个有限假设：在相同相关文档窗口下，更明确的阅读约定能否帮助模型取得尚未展示的细节，同时不过度增加已有充分信息时的读取。

唯一实验因素是系统提示词追加一段一般阅读约定。当前系统提示词是基线，TOOLS、工具描述、实现、初始原文、API配置、预算、用户问题全部固定。追加段不包含任何人物、答案或样本专属规则，不强制Open。未修改生产提示词。

6个既有回归样本：2个角色细节未展示，3个已有充分信息，1个完整占位文档不足以支持指定事实。每组每例3次，共36会话；顺序以918为种子打散，4个API工作线程。问题明确主体，避免此前短查询歧义。每个会话预置同一真实窗口作为合成Search历史，再让模型自主回答或调用工具。后续Search使用真实全库，Open原实现；只禁止引用本会话未见的窗口。4轮后续工具机会加1轮强制终答，用于局部决策验收，不评价长链路停止行为。两组共享此限制。

主检查：未展示细节是否通过实际工具返回变得可见；最终核心答案是否受已观察原文支持。Open增多本身不算改善，从其他文档搜索到直接证据也计为取得信息。自动参考片段定位是窄代理；其他文档等价证据须人工核查，不用答案字符串匹配替代grounding。

副检查：首次动作、后续Search/Open数量；充分信息组额外调用；完整不足组是否把未证实内容当成事实；引用有效性；重复读取；强制终答、API用量。人工记录错误增补和无依据否定，但本轮没有独立新增“禁止发挥”或引用强化规则。

开始API前固定方案、源码、完整提示词、样本和初始返回。报告所有重复结果，不筛选成功轨迹。便利样本仅4篇文档，其中两缺失样本来自同一演员页，不当作独立泛化或统计显著结论。原始及后续语义人工审阅不盲测，结论需保持诊断性质。
