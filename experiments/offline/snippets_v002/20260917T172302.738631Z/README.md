# v002：定位单元后扩展上下文

本轮在 qid=546、1094、517 的历史轨迹上完成 27 次搜索、135 条返回项、59 篇去重文档的离线对照。没有新增 rollout，也没有改动在线 Search/Open。

## 原始问题与实验设计

v001 先按 400-token 上限切块，再用文档内 BM25 选块。换行边界不能保证句子或事件关系完整。本轮尝试先定位句子或行，再向相邻上下文扩展。

A 直接复用 v001 所选片段。B 将正文按轻量标点规则切成句子，Markdown 表格和列表保留为行；使用相同 BM25 公式选择定位单元，再交替向前、向后加入完整单元。一侧达到边界或预算后继续尝试另一侧。最终返回连续原文，最多 400 tokens。超长单元允许切分并标记；无词项命中回退前缀，原始 HTML 保持原有回退政策。

当前只识别 Markdown `#` 标题作为小节边界，未识别普通文本标题、YAML 标题、所有缩写或复杂表格结构；未额外拼接远处的标题、身份信息或表头。每个输出保存原文位置、定位单元、匹配词和扩展停止原因。

需要注意：候选单位从块变成句子/行后，词频、文档频率与平均长度随之变化。因此本实验同时改变了定位粒度和窗口构造，不能视为单独检验扩展操作的消融实验。

## 统计

| qid | 返回项 | A 文本 tokens | B 文本 tokens | 窗口改变 |
| --- | ---: | ---: | ---: | ---: |
| 546 | 50 | 16,818 | 18,734 | 48 |
| 1094 | 50 | 14,711 | 15,901 | 37 |
| 517 | 35 | 11,185 | 13,136 | 32 |
| 合计 | 135 | 42,714 | 47,771 | 117 |

B 的全部返回项均加入相邻单元，本批没有回退或超长定位单元。实际文本 token 总量增加约 11.8%。这是相同上限下的实际消耗差异，不能解释为更节省 token；元信息和 JSON 开销未计入。

## 关键案例

### 517：保留角色记录，未补齐身份

第六次搜索的 67431 命中 `The Constant Gardener | Policeman 1` 所在表格行。B 返回 [1299, 2633)，400 tokens；A 为 [1426, 2634)，368 tokens。B 保留表头、角色与后续影视记录，但新增内容主要是邻近电影介绍，仍没有带回文首的完整姓名和家庭信息。

相邻扩展能够补充附近内容，但文首身份与角色表相距较远，在当前预算下无法同时覆盖。人物身份需要单独的文档信息设计，或通过 Open 读取。

### 1094：短分类词成为定位单元，结果退化

第二次和第六次搜索的 23800，A 返回加时赛后段，至少包含比赛过程和任意球描述，但不满足 95 分钟条件。B 命中文末 `UEFA Champions League Final`，扩展至 [28360, 29954)，返回 370 tokens，主要是流行文化、外部链接和分类信息。

这表明缩小候选单位会改变 BM25 排序。短行与 query 中的赛事词匹配后得分较高，定位偏离比赛过程，后续扩展只增加了偏离位置附近的内容。该例不支持以本版本替换 v001。

### 546：定位变化不能当作上下文修复

第五次搜索的 84585，A 偶然选到包含 Ding Junhui 的末尾比赛记录；B 命中单独的 `Selby` 行，向前扩展到文档开头 [0, 541)，389 tokens。它包含英国公开赛标题与决赛统计，但没有保留 A 中的 Ding 记录。

这次变化更贴近 query 中的候选词，却不能证明更接近题目答案。对于已经偏向错误候选的 query，局部词项匹配仍可能延续原有偏向。

同一次搜索的 55516，B 围绕世锦赛句子扩展，跨过普通文本标题 `2023–24 season`。规则只识别 Markdown 标题，因此未实现实际语料中的完整小节隔离。

## 结论与下一步

本轮验证了定位后扩展的实现、原文可追溯性和预算约束，但未发现足以支持在线替换的一致收益。上下文扩展受定位质量与文档结构识别共同影响。

下一步应先隔离两个问题：一是固定相同定位单元，对比扩展前后的上下文；二是单独评估定位单元是否被分类词、标题或孤立名称吸引。当前定位单元已完整保存，可作为后续配对分析的入口。识别语料中的普通标题和身份信息也应独立记录效果，避免同时引入大量规则。

验证：`python -m pytest tests/test_snippets.py tests/test_snippet_windows.py -q`，5 项通过。测试覆盖连续原文、预算、相邻句子、Markdown 小节边界、表格行、超长单元与无匹配回退。测试通过不代表语义排序或答案正确率改善。
