# v005：固定候选与预算的短窗口构造

上一轮双块共用 400-token 上限时，前缀截取会切断句子或比赛记录。本轮固定 v004 的父块、顺序、各块额度，单独比较块内窗口构造。只评价当前 query 的信息需求，不引入原题其他约束。

## 方案

A 为 v004 的 D_equal_cap：两块各分 200 tokens，短块剩余额度转给另一块，按前缀截取。

B 保留全部已能放入额度的块。需要缩短时，在该父块内部沿用 v002 的句子/行规则，用局部 BM25 选择定位单元，再交替扩展相邻完整单元。所有窗口限制在父块范围内；不重新召回、替换或排序父块，不因新窗口用不满而重新分配额度。

正文使用标点启发式，表格和列表保留行。仅 Markdown 标题被识别为小节边界。超长单元仍允许分割并标记，父块边缘本来存在的截断也不能自动恢复。因而本轮只改善部分结构边界，不能保证完整句子、完整表格或完整事件关系。

选中的父块与分配额度完全固定，但父块内部的可见内容重新按 query 定位。这个变化可能突出相关词，也可能删除理解这些词所需的身份信息。

## 结果

| qid | 返回项 | 块数 | A tokens | B tokens | 内容改变的块 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 546 | 50 | 95 | 19,360 | 18,144 | 85 |
| 1094 | 50 | 86 | 16,864 | 15,629 | 66 |
| 517 | 35 | 64 | 13,025 | 12,306 | 52 |
| 合计 | 135 | 245 | 49,249 | 46,079 | 203 |

204 个块进入局部窗口构造，其中 203 个最终内容改变；41 个可直接放入额度的块保持不变。实际文本 token 量减少约 6.4%，主要因为完整单元放不下时停止扩展，没有强制填满。不能把 token 减少直接解释为效率提升。

有 1 个定位单元来自超长单元切分。21 个块比原前缀覆盖了更少的 query 词项；该词面统计仅为检查信号，不等于语义效果评分。

245 个新窗口均通过实际 get_document 原文回读；所有窗口位于原父块之内，符合原分配额度及每篇 400-token 总上限。4 项相关测试通过，覆盖后部命中、全局字符位置、表格行、原样保留、扩展边界和预算。没有新 API 调用或在线 rollout。

## 人工复核

### 517：角色窗口更集中，身份窗口退化

第六次搜索的 67431，第一个窗口从前缀移至 [1820,2394)，191 tokens，保留表头和 Policeman 1 记录，减少了前部无关演艺描述。

但第二个窗口从文首移至 [630,1426)，196 tokens。它命中 `In 2005, he made his film debut ... The Constant Gardener`，返回职业经历，却丢失 A 中的完整姓名。两块都围绕 query 中的电影词提供信息，却更难确认角色属于谁。

这不是题目其他约束缺失，而是当前 query 所问“谁”的身份上下文丢失。独立优化每个窗口的词项相关性，无法保证多个窗口共同提供可理解的证据。当前实现不应直接替换 v004。

### 1094：保留赛事身份，去掉半句

第六次搜索的 23800，第一块 122 tokens 保持不变。第二块从 278-token 前缀缩为 256-token 窗口，在元信息行结束，不再附带末尾被截断的正文半句。2005 年赛事身份仍然可见，能用于检查 query 中的 2008 年；95 分钟任意球仍未得到支持。

### 546：部分边界改善，记录关系仍不完整

55516 第一块从 227-token 前缀缩至 214 tokens，结束于完整句子，避免截在 `2023 British`。第二块的分类及链接只有 173 tokens，按规则保持原样，因此噪声并未减少。

84585 第二块移至 [634,946)，194 tokens，补入 Selby、Guodong 标签与比赛进程，优于只包含前部比分的前缀。不过窗口开头仍带有上一段统计行，结尾也只保留部分统计。完整行不等于完整比赛记录，赛事身份也没有因此得到确认。

## 判断与下一步

在固定父块与预算下，按句子或行构造短窗口可以减少部分硬截断，但独立按 query 重新定位可能破坏多个片段的互补关系。四个特定实例的人工复核不代表全部返回项的语义有效率。

本轮保留为候选实验，不更新在线工具，也不宣布取代 v004。下一步应先单独验证“保留原前缀位置，仅向完整边界收缩”的版本，将边界改善与位置变化分开。若之后继续采用 query 定位窗口，应明确文档身份如何保留，并纳入相同总预算，避免在局部优化中反复丢失主体。
