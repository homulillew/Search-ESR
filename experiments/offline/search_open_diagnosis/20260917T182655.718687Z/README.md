# Search–Open 局部诊断：固定真实 query 与文档

本轮不评价最终答案、候选纠偏或停止行为。固定首轮在线批次实际产生的 15 次 Search、75 条返回及其顺序，只检查定位、呈现与展开。使用 53 篇去重文档，没有新 API 调用或文档召回。

## 复现与检查范围

75 条 Search 返回与历史结果逐字段精确一致。对每条返回主动探测 before、after、around，共 225 次，各次输出均与原文范围一致。这些 Open 是离线探测，不是模型选择。

17 条 Search 返回已经覆盖全文，17 次 around 都返回原窗口，却统一标记为 no_expansion_within_budget。这项状态错误已单独修正，原诊断结果保留修正前的真实输出。

## 517：父块选择压低了角色记录

固定第五次 query：`Peter King actor The Constant Gardener role policeman`，文档 67431。

| 候选 | 原文位置 | BM25 | 命中词 |
| --- | --- | ---: | --- |
| 人物简介与职业经历 | [0,1427) | 5.872428 | actor, constant, gardener, king, peter, role, the |
| 角色表及邻近内容 | [1426,2634) | 4.927818 | actor, constant, gardener, king, policeman, role, the |

当前是普通 BM25 累加：它不把 policeman 视为必须出现的查询条件。简介中的姓名及其他词项匹配让第一块获得更高分。进入第一块之后，句子级排序又将完整人物介绍排在首位，最后展示 [0,1299)。角色表位于未选中的父块，没有进入局部锚点竞争。

窗口构造器虽然能跨父块扩展，但从人物简介位置出发，400-token 预算不足以到达后面的角色表。因而这次失败主要发生在定位与预算组合处，不是原文读取错误。

离线调用 after 返回 [1299,2790)，包含角色表；around 返回 [0,2790)，覆盖整篇并包含角色表。说明当前 Open 能一次补足当前 query 所需内容。不能从这项能力测试推断模型会主动使用它。

## 546：数字拆分与部分匹配影响定位

固定第一次 query：`snooker player decider game 2023 win 4-3 4-0 loss over 400 centuries`。

4975 的最高分块位于 [112652,113468)，BM25 21.200011，匹配项为 `0,2023,3,4,snooker`。原分词将 4-3、4-0 拆成 4、3、0，并去重 query 词项。窗口最终包含 0–3 等结果统计，不能据此满足原 query 的比分关系。大量年份、比分和序号使这些词项容易匹配到统计表。

38231 的最高分块位于 [21738,22624)，BM25 11.387596，匹配 `centuries,decider,game,win`，没有 2023。局部锚点又选中 `World Cup win (2017/2018)`，最后窗口覆盖附近旧赛季内容。这里不是缺少原文，而是排序允许某些 query 词项完全缺失，且短标题在局部候选中得分较高。

本轮不据此要求模型更换候选，也不将 2023 设为所有任务通用的硬过滤条件。下一步应在同一输入上独立检验数字/比分表达的保留，以及局部锚点是否保留父块中关键匹配，不能同时替换多种排序机制。

## 1094：全文已返回，继续展开没有新原文

39918 全文为 372 字符，只有标题、占位符和导航项。Search 已返回 [0,372)，before/after 均标记 document_boundary，around 却标记 no_expansion_within_budget。不是读取预算不够，而是没有更多原文。

已作最小修正：around 在原窗口覆盖整篇时返回 document_complete；尚有原文但无法在预算内扩展时继续使用 no_expansion_within_budget；before/after 的方向边界语义不变。窗口引用、文本与排序均未改变，不额外隐藏或过滤该文档。

## 当前结论

本轮确认三类局部问题，需要分别验证：

1. **定位**：普通 BM25 不保证角色词、年份或比分关系得到保留；父块与局部锚点两级选择可能进一步放大偏差。
2. **呈现**：跨父块窗口能提供上下文，但无法补救远离目标的锚点，也不保证表格行组成完整事件记录。
3. **展开**：517 的上下文可通过一次 Open 读到；完整文档的状态表达存在确定错误，已修正。

下一步优先处理 517 的父块定位，以同一 query、同一文档比较候选，检查角色关系能否在预算内显露；另设 546 比分分词对照。最终答案、gap 和模型提交行为不纳入这些局部实验。
