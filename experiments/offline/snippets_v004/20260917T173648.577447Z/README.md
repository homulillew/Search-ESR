# v004：空白重叠修正与相同总预算上限

本轮沿用 27 次历史搜索、135 条返回项，只评价当前 query 的信息需求。原始文档、召回、分块、BM25 排序保持不变，没有新增 LLM 调用或在线 rollout。

## 两步对照

| 组别 | 选择与呈现规则 | 每篇文本 token 上限 |
| --- | --- | ---: |
| A | 原 top-1 | 400 |
| B_strict | 原先严格字符不重叠的 top-2 | 800 |
| C_whitespace | 仅含空白的交集允许共存，其他重叠仍排除 | 800 |
| D_equal_cap | C 的两个块各分 200；短块剩余额度转给另一块；从各块开头截取 | 400 |

B→C 单独检查空白重叠修正。A→D 比较相同总上限下的一块与两块。D 保留 C 的候选与排名，但会改变可见范围；这也是本轮刻意记录的取舍。截取没有句子或表格完整性保证，不代表所有等预算多块方案。

空白交集按原文 `strip()` 后是否为空判断，不改写原文，重复空白照常计入各块预算。裁短的片段保存原块 ID 和新的视图 ID、原文位置，避免同一个块 ID 对应不同文本。原文回读使用现有 get_document。

## 统计

| qid | 返回项 | B 双块数 | C/D 双块数 | A tokens | B tokens | C tokens | D tokens |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 546 | 50 | 45 | 45 | 16,818 | 31,887 | 32,003 | 19,360 |
| 1094 | 50 | 36 | 36 | 14,711 | 27,022 | 27,109 | 16,864 |
| 517 | 35 | 24 | 29 | 11,185 | 19,224 | 21,255 | 13,025 |
| 合计 | 135 | 105 | 110 | 42,714 | 78,133 | 80,367 | 49,249 |

空白修正改变 14 条返回的候选选择，其中 5 条由单块变为双块，其余替换了第二块。A 与 D 每篇上限相同，但 D 实际文本量增加约 15.3%，因为 A 经常没有用满上限。因此不能声称实际成本完全相等。JSON 和元信息不计入该文本预算。

四组中相同返回项的相同范围去重后，共 458 个原文范围通过实际 get_document 回读校验。所有片段符合各自预算。新增预算测试与已有多块测试共 4 项通过，覆盖空白/非空白重叠、排序、预算转移和原文位置。

## 当前 query 下的人工复核

### 517：400 tokens 同时提供姓名与角色

第六次搜索的 67431，原规则因一个换行交集排除身份块；修正后允许该块与角色块共存。D 第一块为 [1426,2163)，200 tokens，仍包含表头和 `The Constant Gardener | Policeman 1`；第二块为 [0,619)，200 tokens，包含 Peter King Nzioki Mwania 姓名、别名和演员身份。

两块共同支持理解“该电影的 Policeman 1 对应谁”，优于仅返回角色表而缺少人物身份的视图。本次 query 不要求家庭背景，因此其截断不计为缺失约束；但句末截断仍是呈现上的限制。该结论是原文人工复核，没有在线模型效果数据。

### 1094：短块让出额度，保留赛事不匹配信息

第六次搜索的 23800，第一块仅 122 tokens，D 保留全部，并将第二块额度提高至 278。第二块仍显示 2005 年赛事身份，可用于核查 query 中的 2008 年；仍没有证明 95 分钟任意球这一事件。增加身份信息不能等同于满足完整 query。

### 546：噪声块占用额度，记录可能被截断

第五次搜索的 55516，第二块为 173-token 分类及链接内容，第一块只剩 227-token 额度，末尾截在 `2023 British`。第二块没有补充 query 指定赛事结果，却压缩了正文空间。

同次搜索的 84585，两块均裁至 200 tokens，第一块截断统计项，第二块只保留半决赛部分比分，未保留该段后续选手标签。按固定前缀分配预算不能保证事件记录可独立理解。

## 结论与后续

空白重叠修正解决了已确认的候选误删问题，可以保留为选择规则。相同总上限下，多块在 517 和 1094 的特定实例中保留了有用信息，但分类噪声和截断损失仍然存在。本轮人工复核四个特定条目，没有计算全体语义有效率，也没有答案准确率结论。

下一步可以固定本轮候选和总预算，单独比较前缀截取与围绕命中内容、按完整句子或记录构造的短窗口；第二块噪声的选择问题应另行评估。当前在线 Search/Open 未修改。
