# A1 conditional evidence-acquisition replay

Predeclared start condition: a selected deployable document-ranking policy from K0 or Q1, followed by completed F1 and selected Find policy from F2. If started, use all 40 frozen cases with exactly two decisions (full-corpus Search batch, then Find batch), no Reader/Claim/Verify, and review useful/fully sufficient W. The proposed gate is A/B >=85%, C/D >=75%, overall >=80% useful evidence. Preserve per-case AQ/DR/FL/ST/mixed failure attribution.
