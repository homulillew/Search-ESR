# Search–Open 同预算局部回归实验

本实验固定查询和文档，只考察返回窗口。冻结清单中的全部文件哈希验证通过，未修改生产实现。复用原有20个人工局部需求：19个有单一参考片段，1个不匹配控制不纳入命中率。此为既有样本回归，不是独立泛化评估；没有调用模型，也没有重新检索文档。

## 对照设计

主对照为 prefix400 和 windows400：均携带相同原文标题，标题与正文合计最多400个 Qwen3-Embedding-8B tokenizer tokens。前者从文首截取，后者使用冻结 Search 的查询定位窗口。参考标注不传入窗口构建。

继续读取统一使用一次固定 after，不根据答案选择方向。前缀组从初始末尾读取最多1200 token（含重复标题）；窗口组使用原生 open(after)，同样最多1200 token。两组原文区间可合并，因此跨两次返回边界的参考片段也可计入。所有切片与原文、预算上限均通过断言。

另保留1600字符前缀辅助组，但它使用统一标题和本实验续读策略，不代表完整旧工具的历史表现。比较的是相同预算上限，不保证实际返回长度逐条完全相等。token统计只含标题与正文，不含JSON元数据、提示词或模型输出，不是API费用。

## 结果

|方案|首次参考片段可见|固定after后累计可见|首次标题+正文tokens（20例）|含一次after累计tokens（20例）|
|---|---:|---:|---:|---:|
|1600字符前缀，辅助对照|13/19|17/19|8130|18526|
|400 token前缀|13/19（68.4%）|17/19（89.5%）|7704|18270|
|当前400 token窗口|16/19（84.2%）|18/19（94.7%）|7490|18177|

主对照首次提升15.8个百分点，逐例3胜、16平、0负。固定续读后1胜、18平、0负。首次实际返回tokens少2.8%，加一次续读后少0.5%，因此不支持显著成本下降的结论。样本少且同一文档有多个需求，不能把19例当成19个独立文档推广。

## 改善来自哪里

- local_09：Riise在加时末段的任意球。参考区间位于16479–16518字符。前缀400仅覆盖0–1311；查询窗口覆盖15709–17331，直接展示相关事件。固定一次前缀续读仍未到达该位置。这是文内定位的直接收益。
- local_14：What-a-Mess正式名称。参考区间1804–1844，前缀止于1662，当前窗口1014–2706。窗口使相关信息首次出现；前缀继续读一次也能覆盖。
- local_18：Gromenkova决赛对手。参考区间1985–2013，前缀止于1746，停留在更早的淘汰过程；窗口1095–2773包含最终对手及结局。此实验只证明相关原文可见，不重新声称模型误判率下降。

后两例在续读后差异消失，说明主要收益是信息更早出现，不是前缀永远无法取得信息。是否因此减少模型调用，仍需模型自主阅读对照，不能从固定一次读取实验推断。

## 仍存在的问题与指标边界

local_01和local_05的电影角色行仍未首次命中，两组向后读一次均能覆盖。当前定位并非总能把最直接片段放入Search。

local_08的参考片段位于16140–16213，但当前窗口落在26935–28495，包含同一117分钟扑救的另一处叙述。自动指标把它算作未命中，不能据此说没有提供相关信息。本次不根据新结果追加有利标签，保留原始计数。下一步应在比较前独立标注多个可接受证据位置，并区分片段出现和上下文足以解释。

不匹配控制只能核验工具返回，不能测模型是否错误推断，因为本实验没有模型。主体身份、表头归属、截断误导也未做完整人工评分，不能由命中率替代。

本结果支持的有限结论是：在这些既有查询和文档上，当前查询窗口用相同预算上限，让更多预先标注的相关原文首次可见。它没有测文档召回率、模型是否主动Open、gap、最终答案正确率或泛化效果。继续冻结实现，优先用新的局部需求及独立多位置标注验证，比立即增加窗口策略更有价值。
