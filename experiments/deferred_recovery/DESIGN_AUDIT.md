## Required design judgments

1. **Immediate versus eventual recall.** A Claim Writer is a lossy compressor. Missing an observation-to-Claim admission is not necessarily permanent loss if ordinary future acquisition and re-admission can recover the information when needed. Eventual recall requires both visible grounded evidence and its usable persistent representation; retrieval alone is insufficient.
2. **Deferred Recovery.** A previously observed fact is absent from current Claims and later becomes an unresolved active requirement. The experiment projects a real historical state into that later focus, retains real D/W registries, hides old raw windows, and measures reacquisition plus U1 re-admission. This is a controlled focus-shift probe, not evidence that an autonomous controller naturally selects that future need.
3. **Eligible v3.1 omissions.** q311 exact runtime during name/cast investigation is D3 with D4 refinement. q546 fifth career maximum during match-sequence investigation is potentially D3. Prefix review must check that existing Claims do not already solve each need. Other cases cannot inherit these classifications by analogy.
4. **Conflict is special.** q186 source-specific 1993 versus an existing 1992 belief has immediate revision value. D2 is a separate safety cohort, never evidence that ordinary deferral is safe. Later recovery does not undo decisions already made from a conflicting belief.
5. **No recovery tool.** Recovery is an offline information-event label. Runtime tools remain Search/Find/Open, with Actor Stop. A new source can satisfy the need as validly as the original source.
6. **No semantic Harness router.** Code cannot judge unresolved requirements, source relevance or sufficiency to route Workspace before corpus. It only projects context, validates contracts/handles/budgets, executes Actor choices and records provenance. Semantic judgments are offline.
7. **v3b limitation.** Orthogonal Search returns already-discovered metadata and existing previews for known documents; it deliberately does not relocalize them for the new query. This prevents a clean unified-global recovery test.
8. **v3a semantics.** SearchFindTools calls the existing global Search path for every query, then attaches stable handles. Its underlying search localization must be verified on three actual corpus documents after bank freeze. Retriever, ranking, localizer and v3b remain unchanged.
9. **Only main arm difference.** Both arms use identical v3a Search, corpus and input projection. G exposes Search; H additionally exposes Find/Open. Each has at most two decisions and one action per decision. Both can Stop. Available-tool contract text necessarily differs. No preferred local-first order.
10. **Leak prevention.** Actor sees original Q, real Claims, working hypothesis, answer-free requirement, D/title/URL catalog, only new attempts and budget. No historical raw window, W target, reviewer label, target ranking, private truth or selected-source flag. Catalog is identical across arms and mechanically complete for the prefix. Old registry windows remain private; only newly exposed W handles are actionable by Open.
11. **Success.** A new observation supports/refutes the active requirement and U1 writes its necessary grounded relation. Exact old W recovery is unnecessary. Old-source Search, local reuse and new-source recovery are separately labeled. A premise embedded in the question is not evidence.
12. **Failure layers.** No sufficient observation across both decisions is retrieval failure. Sufficient observation without a usable Claim is re-admission failure. Premature Stop/ineffective choice with available usable evidence is Actor control failure. H local failure paired with G success flags source lock; repeated wrong-local choices are separately recorded. Interface/provider/tool failures retain their own labels and denominators.
13. **Bounded exploration.** Only if primary recovery misses its gate, one committed and frozen follow-up may target a demonstrated failure layer: query instruction, fixed k=10 if ranks6–10, mechanical catalog projection, actual v3a bug repair, or narrow Writer active-focus clarification. At most12 cases/24 Actor calls or equivalent Writer scale, one remedy only. It never changes the primary gate retrospectively.
