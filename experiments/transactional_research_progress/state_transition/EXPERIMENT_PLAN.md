# E1: Full Rewrite versus Delta versus Delta + Triggered Verify

The case bank was built from exact historical source text and prior real one-step observations, with 41 cases across 12 qids. T1/T2/T3 share some source text as deliberate counterfactual local Claims. The eight T4 cases introduce no evidence for their specific committed Claims. T5 splits an observed source into three independently checkable Claims. Four T6 cases make a narrow ActiveGap resolvable. T7 introduces a real apparent source conflict on Galacta's release year; its title-equivalence ambiguity is explicitly medium and analyzed separately. Packet-local W# aliases for baseline sources are provenance mapped and not passed off as historical Actor handles.

Each arm receives the same previous VerifiedProgress, ControlProjection, previous observed excerpts (where needed), original relevant question constraint, and one new exact observation. The private transition label and reviewer mutation table are never included. Arm order rotates A→B→C, B→C→A, C→A→B. Each case/arm is sampled once. B and C use identical Updater request bytes. A's complete-state rewrite is a diagnostic comparator; B's unverified commit is an ablation. The deployable invariant is tested in C.

Mechanical validation checks object shape, exact W refs, allowed Claim/Gap IDs, new-claim-open rule, nonempty cited refs for semantic mutations and uniqueness. No semantic error is repaired. C sends only the exact relevant question constraint, Claim, and cited exact observed excerpts to a separate verifier when the Delta attempts closure/reopening or dependent gap closure. If it disagrees, the old committed Claim status remains, and dependent gap close is rejected. Harness increments versions and retires an ActiveGap whose Gap actually closes. A is not given these semantic repairs.

The primary comparison is paired unrelated-state churn A versus B/C. The second is B versus C false closure and precision. Report all transition types, qid clusters, evidence binding, NoGain preservation, stale gap and unsupported promotion. The predeclared gate in `RUBRIC.json` controls whether E2 is allowed. An E1 failure stops this branch's downstream model experiments.
