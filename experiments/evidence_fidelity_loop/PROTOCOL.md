# Evidence Fidelity protocol

Base is remote `experiment/gap-evidence-claim-loop` at `4b460c76f9ec9aaeaa5b4255f142d8c31c64b26d`. Historical experiment trees are immutable. The research asks whether real tool evidence reaches Reader, Verifier, and Gap Reviewer without losing source identity or inventing relations.

Stages run in strict sequence: E1 full evidence packet; E2 exact support verification only after E1 passes; E3 Claim-only Gap sufficiency only after E2 passes; F3b paired single-Gap rollout and runner fixes only after E3 passes. Every stage has its own pre-call freeze and zero retries. Failures and invalid responses remain in denominator. Absolute reliability gates apply even if comparator is near ceiling; superiority gates activate only at the frozen baseline-error threshold.

E1 uses 44 historical observations across 12 qids. T and P receive identical DeepSeek system prompts and Q, Gap, Claims, W text; P also receives observed D, title and URL. Arm order alternates over a hash-sorted case list. Exactly one response per cell, maximum three findings. `evidence_packet/REVIEW_RUBRIC.md` fixes the labels and metrics. A semantic reviewer scores every finding, including any unexpected extra finding, before stage gate. Model outputs never become reviewer truth.

E2, if entered, must include every actual E1-P finding plus 20–24 genuine-W stress packets (temporal, identity, sequence, partial conjunction, title+body, legitimate two spans), then compare whole-packet V0 with max-two-span V1. Offset and metadata allowlist validity is mechanical; support sufficiency is semantic. V1 requires commit precision ≥97%, recall ≥90%, temporal/identity/sequence false accept ≤5%, pointer validity ≥98%, stress negative rejection ≥90%. If V0 has at least five clear false accepts, V1 also needs at least four net paired fixes with at most one reverse worsening.

E3, if entered, uses 36–44 Q+Gap+verified Claims packets across at least ten qids, with no raw W. It compares binary C0 against supporting-Claim-ID plus missing-field C1. C1 requires premature closure ≤5%, missed closure ≤10%, near-complete trap rejection ≥90%, full-resolution recall ≥90%. If C0 has at least five premature closures, C1 must improve those paired cases.

F3b, if entered, fixes the runner first: maximum four executed tool actions; one tool action followed by full evidence-state transition; pending `(Gap,W)` processed once before another actor action; immediate stop and queued-action discard after resolution. Both paired arms share these runner fixes and the same compact Actor View and Search/Find/Open backend. B0 retains text-only Reader, whole-window Verifier, binary Gap Review, and no pending-first policy. B1 uses full packet Reader, pointer Verifier, sufficiency Gap Review, and pending-first. Group A conversion and Group B retrieval-limited qids are pre-registered separately. No new persistent Research State fields or hard tool gating.
