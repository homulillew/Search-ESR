# E2 frozen reviewer rubric

All 46 actual E1-P Findings enter Part A without selection; 22 new candidate statements enter the stress bank. Every W text is a byte-for-byte historical observation. `BANK.json` freezes truth before E2 calls. `source_supported` is true only if the current complete packet directly establishes **every** substantive identity, date, quantity, time, sequence, and entity relation in the Finding. Separate true facts in one W do not establish their relationship. `claim_eligible` additionally requires novelty and material relevance to the current Gap; it is a secondary admission diagnostic, never silently substituted for source support.

V0 and V1 receive identical Q, Gap, committed Claims, Finding, and complete packet. They differ in verifier prompt and V1 pointer output. A supported V1 response is mechanically valid only with one or two spans, integer `0 <= start < end <= len(text)`, current `window_ref`, and a list drawn only from nonempty `title` and `url` metadata fields. An insufficient response requires empty support and metadata lists. Invalid output or API failure counts as insufficient, with raw output and error retained. No repair, retry, or best-of.

The reviewer separately judges whether V1's **pointed** spans plus explicitly named metadata fields establish the complete Finding. A mechanically valid but semantically insufficient pointer cannot commit even if its free-text reason sounds plausible. V0 supported verdict commits for the support-only metric. V1 commits only when the verdict is supported, schema and pointer are mechanically valid, and the pointed support is semantically sufficient. A rejected genuine positive is a missed commit; an accepted negative is a false commit. Full Claim-eligibility precision, including Gap relevance, is also reported, keeping the four off-Gap Part A Findings visible.

Primary gate uses complete-source-support labels because E2 isolates exact evidence grounding: V1 support-commit precision ≥97%, support-commit recall ≥90%, each S1 temporal/S2 identity/S3 sequence false-accept rate ≤5%, pointer validity ≥98%, and S1–S4 negative rejection ≥90%. Denominator for pointer validity is all V1 raw `supported` verdicts, including malformed ones. For S1–S3, false-accept denominator is all four negatives in that class. If V0 has at least five clear false accepts, V1 also needs at least four net paired fixes and at most one reverse worsening. Small denominators are always shown. Any error stays in the denominator.
