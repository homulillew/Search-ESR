# Frozen hypotheses

- H1: Tool evidence can lose document identity, publication context, or time when the Reader sees only W text. Complete packets should recover those findings without metadata overreach.
- H2: Whole-window support permits two true but unrelated facts to be joined into an unsupported Claim. Exact supporting spans should reduce false temporal, identity, and sequence binding.
- H3: Unprocessed useful W can trigger redundant retrieval. A deterministic pending-W queue should consume current evidence before new tool actions.
- H4: Claims covering most of a Gap may still omit a required date, identity, sequence, or source relation. An explicit sufficiency review should reduce premature closure.
- H5: Decision-level horizons and queued calls let retrieval continue after a Gap resolves. Per-tool transitions and immediate stop should eliminate that execution artifact.

The existing F1 Gap filtering and F2 independent Verifier results are treated as historical findings, not re-estimated here. A Claim remains a verified, committed factual belief with only ID, statement, evidence refs, and version.
