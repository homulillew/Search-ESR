# F1 Research Frontier Control

The bank contains 24 distinct corpus-document windows from ten qids. Each window is a genuine historical Observation from the frozen E1 packet bank, verified as a unique exact slice of the local BC+ corpus before calls. The prefix is deliberately reconstructed from that one historical W plus source-supported factual Claims already frozen in V1. These diagnostic prefix reconstructions are **not** claimed to be the complete historical trajectories. No future tool result or gold answer is used to choose a cell or an eligible/preferred Gap.

For each cell, the reviewer froze two to four semantic Open Gaps, eligible Gap IDs and a preferred next Gap. Preferred is a diagnostic label, not the sole success criterion. Both arms receive identical Question, Claims and Workspace. A0 receives all Open Gaps. A1 first calls a selector on all Open Gaps; the Actor then sees only the selected Gap. The same Actor prompt and full Orthogonal `search/find/open` schema serve both arms. Exactly one Actor tool call is allowed and is actually executed against the frozen BC+ corpus. All three tools remain available; no action mask is used.

One W from the real action is useful if it contributes a new source-grounded fact that materially advances any frozen Open Gap beyond the initial Claims and W. An already visible or Claim-covered fact alone is redundant. `NoGain` means no new useful W from the action. Frontier-specific progress applies the same test to A1's selected Gap. Scope correctness checks the Search/Find/Open choice against currently known D/W. Scatter marks a query/action that mixes distinct Gap topics so broadly that no one is inspectable. A source can be relevant yet its returned window can fail to yield useful evidence. Review every action result without consulting gold answers or later trajectories; keep per-W reasons.

Gate: if A0 has at least five NoGain/scattered/wrong-focus cells, A1 needs at least four net paired useful-evidence improvements, at most one reverse worsening, no decrease in useful-evidence rate and no increase in NoGain. If A0 is near ceiling, report feasibility without forcing superiority. Invalid model or tool results remain failures. Multiple checkpoints within a qid remain correlated; report qid-level breadth.
