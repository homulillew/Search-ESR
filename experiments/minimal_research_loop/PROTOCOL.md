# Minimal Research Loop protocol

Base: remote `experiment/evidence-fidelity-loop` at `9cf044ddbfad022cb8e5c0a1e689b715b84421b3`. Historical experiment directories are read-only. Four stages are ordered V1 Verify Necessity → F1 Research Frontier Control → C1 Gap Closure Reliability → R1 Minimal Single-Gap Loop. V1/F1/C1 are local diagnostics; R1 requires a deployable V1 commit policy and C1 closure policy. F1 is not an R1 gate.

Harness owns D/W identity, text, title, URL, date, boundaries, visited/processed windows, Claim IDs, W evidence binding, tool budget, action trace and stop. Models output semantics only. The default evidence unit is the existing W. No model-generated document/window IDs, URL, offset, pointer, confidence, planned Claim graph or TestCard persists. Claims are verified factual beliefs, and the active Frontier is only one selected `gap_id` from the open semantic Gaps.

Every stage freezes its own HEAD, provider, case/arm order, input and prompt hashes, reviewer labels, rubric, gate and failure policy before relevant model calls. DeepSeek `deepseek-flash` is fixed, with one call per cell, zero retries, no repair and all errors retained. Stage artifacts are immutable after calls; later decisions are recorded in separate files. Stopped stages get explicit NOT_RUN records.

V1 reads 52 genuine historical W packets once each with the same Gap-conditioned Reader, then freezes all natural Findings and single-reviewer support/relevance/novelty labels before any verifier call. Direct Commit is deterministic, with W refs bound only by Harness. The Verifier sees only the candidate statement and current Observation. It outputs one boolean. Source-support and complete Claim precision, supported recall, false promotions/rejections, latency/tokens and extra call count are reported separately. The user-specified A/B/C policy decision is applied without assuming Verify is needed.

F1, if reached, compares implicit versus explicit `gap_id` Frontier over 24–32 prefix-only historical checkpoints and executes one real Orthogonal Search/Find/Open action per arm. C1, if reached, compares binary versus missing-first closure over 40–48 Claim-only packets. R1, only after V1 and C1 yield deployable choices, fixes four tool actions, pending-W-first processing, one tool per actor decision, and immediate stop, in 8–10 single-Gap qids. No current stage expands the State schema.
