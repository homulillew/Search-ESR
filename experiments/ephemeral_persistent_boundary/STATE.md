# Minimal state and action trace

Persistent ResearchProgress: explicit provisional WorkingHypotheses with basis,
SemanticGaps, natural TestCards (`condition`, `known`, `unknown`,
`open|satisfied|refuted`, evidence refs), and only verified evidence-backed
bindings. WorldLedger keeps every action and observation for audit. The Actor
may use a query hypothesis for one action; the Binder and Verifier receive only
the current TestCard, committed bindings and exact new Observation in the
isolated treatment. A query guess never becomes evidence by being queried.
