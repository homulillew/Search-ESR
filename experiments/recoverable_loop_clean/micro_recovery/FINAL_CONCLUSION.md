## 结论

**本轮没有通过完整恢复闭环的执行门槛；恢复机制结论仍不确定。**

API 层工作正常，但12条轨迹最终全部被 H 引用校验截断。错误主要来自
`basis_refs` 的命名空间：模型输出了实际存在的 R#/C#/D#，执行器要求 W#。
Schema 只把它定义为通用字符串，Prompt 也未明确说明“只允许 W#，引用新 C 时
应使用它的 evidence_refs”。这是这版接口表达与运行时检查不一致的重要问题。
不能据此得出“模型不能从 NoGain 恢复”或“Research State 无效”。

局部结果有正向信号：4次不完整状态的 Closure 均正确 veto，并实际进入下一 Actor；
其中2条轨迹获得新的有用原文。5条新 C 均获得其完整实际窗口支持。
但 H 更新大量失败，R1没有任何后续 Actor 机会，R2没有成功提交任何 H 变化。
这些局部信号不足以宣称闭环成功或扩大实验。

## 三类恢复

| 通道 | 观察 | 可支持的判断 |
|---|---|---|
| R1：次优动作后恢复 | 4次冻结的重复 Search 均无新窗口；4次 H 更新失败；后续 Actor0次 | 没有测到所需恢复机会，不能判定 NoGain 策略是否有效 |

| R3：提前 Closure | 4/4正确 CONTINUE，4/4进入下一 Actor；2/4在最多3个决策内获得新有用原文 | 存在部分纠偏进展；无完整终局恢复证明 |

两次“单次 acquisition NoGain 后仍有下一 Actor”的机会都发生了检索范围切换：
Ding 从 Search 转 Find；Euler 从无关 essay 的 Open 转新书籍 Search。
这不是预设的“两次连续 NoGain 后换路线”检验；后者实际机会数为0。
R3的首步是人为触发 Closure，不能推断自然 Closure 请求频率，也没有未加 veto
的对照组支持因果效应量。

## 事实边界与有用信息

- 模型生成的10个 acquisition 动作均结构合法、可执行；另有4个冻结干预动作。
- 1/10模型 OneGap 明确硬化前提：把 Kwon 的“截至2019无子女”写成已知条件。
  该次 Reader 返回空 finding，没有把此前提写入 C。
- 5/5新 C 有来源支持，均保持局部表述；没有把局部事实写成全局答案已成立。
- 其中3条来自**已观察窗口的重新提取**：两个 FOP局部诊断、一个 Ding2019属性。
  只有2条来自新增原文：信件的 North Transylvania 段落、书籍目录。
- 因而不能把5条新 C表述成5次新证据发现。
- 7次 Find/Open 中，单人审阅认为6次来源适合所述调查方向；只有1次带来新增
  有用原文（信件 Open）。这两个描述性比率不能与不同历史 cohort直接比较。
- 没有观察到 false C（0/5）或 false READY（4次不完整状态审计均 veto）。
  READY实际次数为0，不能估计 READY precision；没有最终答案生成。

这些分母很小且同一问题有重复，两次 FOP Claim 也不是两个独立事实。
不报告显著性，不把“未观察到错误”表述为通用事实安全保证。

## H 层：接口与语义问题需要分别处理

14个 H 响应中12个违反 W-only 引用检查；另2个只是合法 KEEP。
所有实际 H 写入均未改变原 H 内容或状态。12条失败轨迹的原始输出全部保留。
q546两个响应还把旧 D17重复提名为“新发现 source opportunity”，是另一条
机械条件不满足；即使只修 basis_refs，它们仍不能按本轮规则提交。

不能把所有问题归为引用格式。审阅还发现未提交的语义风险：

1. q546某响应在没有新 Observation 时给出 Tom Ford及完整比赛顺序的强判断。
2. Euler某 H 把没有给出目标书条件的 Euler论文/发明家列表描述成支持一个满足
   插图、除锈、人物引用条件的候选书。
3. q637有响应根据单篇候选报告的 FOP诊断，直接提出拒绝全局 SPS假设；两篇报告
   与问题的绑定仍未完成。
4. memo H提出用“1944年转向事件→memo日期”替换“即位→信件日期”的时序关系。

这些内容没有进入 C，相关 H 提议也因接口校验未提交。单纯把 D#/C#/R#自动映射成
W#会掩盖问题，不能作为本轮结果修复方式。
