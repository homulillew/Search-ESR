# Frontier generation protocol

Base `9e4b48c197d4248e2ccf34850948761706252cfd`; audit committed before implementation. Primary intervention: information view, with identical Frontier instruction, unchanged model/provider, JSON mode and no tools. Need is ephemeral; no runtime Requirement Map or persistent fields.

## F0

Inventory114 actual G4/G5 checkpoints; mechanically select24 across10questions. `bank/SELECTION.json` pins selection. Exact full States are archived; production S projects every Claim statement verbatim plus actual Working Hypothesis. It excludes private provenance and machine records. History preserves exact source exposures, Actor Need and tool actions/results in chronological order. It excludes Updater outputs, residuals and oracle summaries. No selection from new outputs.

**Boundary:** complete *recorded replay episode*, not complete ancestral research. The episode starts with the seed’s actually exposed source windows; the pre-seed chronology is not fully recoverable. Some seeds were reviewer-normalized in historical work, and later Claims came from the legacy Writer, not U1. No cleaning or synthetic replacement. Thus this is a diagnostic of these exact inherited States, not a fresh end-to-end evaluation of minimal U1 State. G4 starts from archived PRE Workspace to avoid importing future windows.

`REQUIREMENT_MAP.json` is question-derived. `COVERAGE.json` is single-reviewer prefix-only, frozen before calls, with S/H/Combined coverage, Claim/source references, conflicts and subrelation notes. Primary closure requires the material original clues plus requested relation for one candidate. F24’s historical discriminative-identity closure is a separately predeclared sensitivity. A resolved composite is sufficient to establish that local property, not all target identity. In partially resolved composites, reasking an already known subfact can still be stale; the frozen notes govern.

## F1

24×3views×2independent submissions =144 planned calls. H: Q+recorded history; S: Q+Claims+Hypothesis; SH: both. Identical round, one available Frontier decision and last<=2tool/query/status tuples. No Workspace or labels in shared context. Both replicates count; no retries, replacement or best-of. Deterministic hash-shuffled request order, concurrency4, timeout240s, provider defaults, JSON mode with local deterministic schema validation. No reasoning text is evaluated.

Raw request/start/completion, response, error, usage, latency and commit HEAD are preserved. Failed requests count invalid in the planned denominator. An auth error blocks further queued calls and all blocked slots count failures. Interrupted started calls cannot be resubmitted. Rerunning an existing event file is refused.

Masked semantic review hides arm, replicate and condition IDs; packets are shuffled and contain the actual view and corresponding frozen coverage. A reviewer may infer treatment from view format; no claim of perfect blinding or independent reviewer replication. Evaluate one Need, map to any eligible frozen requirement(s), retain reason and flags. Do not require a unique gold Need. See `analysis/RUBRIC.md`.

F1 gate: S valid decision rate>=85%; SH−S<=5pp; fewer than3added critical checkpoint failures spanning>=2qids. Added critical checkpoint=at least one S replicate has premature stop/drift/unsupported premise, while both SH replicates are valid and noncritical. Count a checkpoint once, never treat replicates as independent cases. SH advantage>=10pp or>=3such repaired checkpoints across>=2qids refutes sufficiency. Long-term blocking omission cannot be inferred from two static choices; report unmeasured in F1 rather than manufacture it. Passing requires every gate condition; no significance threshold or best-of.

Primary denominator144; arm48; perqid includes all its checkpoints. Also report valid act among acts, correct stop, premature/missed stop, error rates, S deferred reactivation opportunity and realization (including separately marked subrelations), paired replicate categories, perqid and 4 equal H input token rank groups. Need+stop valid is the gate metric. A failure is not a semantic hallucination. Missing usage is unknown. Cache rate=sum(hit)/sum(input) on usage-reporting requests. Reasoning tokens are an inference-burden proxy only; missing values are never zero-filled. No dollar costs without an explicitly frozen price. Concurrent latency and cache warmth limit causal speed inference.

## Later stages and one exploration

F2 only on passing F1: freeze12real transitions>=6qids, actual pre/post, H/S/SH once each=72calls. T1resolvedfocus/T2contradiction/T3independentrequirement/T4closure. Gate S>=80%appropriate shift/stop,<=10%stale, no material SH deficit. No synthetic post Claims.

F3 only passing F1/F2: same poststates P(actualpreviousGap),D(direct),R(Question+Claims Reviewer without Hypothesis then residual+State). No tools; extra Reviewer must earn benefit, never presume P inferior. Freeze exact arms/budgets and criteria before calls.

F4 only if mechanism qualifies:8–12reserved real cases>=6qids, no F1/F2 tuning checkpoints; report same-qid overlap. D/R and P unless clearly inferior by frozen F3 rule,<=3decisions,oneactioneach, unchanged v3a Search/Find/Open and U1. Autonomous Need→Evidence→scopedClaim; no supplied RecoveryNeed. Separate generation, retrieval, localization, admission, hypothesis/control, stop and horizon failures.

If a gate fails, optional **one** bounded A–E exploration only after separate committed plan, <=12checkpoints/24Frontier calls or8mini-loop cells. Primary gate cannot change. Unrun stages remain unmeasured.

Historical files, runtime components, corpus and source truth are immutable. Commit and push the experiment branch without rewriting history.
