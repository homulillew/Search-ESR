# Hypotheses frozen before calls

1. Q/R/C/H/T is sufficient for useful next investigations without exact residual.
2. Wrong/weak H usually leads to testing, not downstream factual commitment.
3. Two explicit NoGain outcomes induce semantic route changes, not just paraphrases.
4. Resurfacing an uninspected source affects source use or motivates a better global
   alternative. This endpoint is descriptive (2 states).
5. Some support-alignment errors may become low-cost repeat investigations, while
   completion remains a separate Closure responsibility. This batch measures only
   proposed actions; actual costs, closure protection and successful recovery are
   not inferred from one-step behavior.

Failure alternatives: C ignored; H hardened; trace not acted on; insufficient
source description; coarse R not translated into action. A single failure is not
evidence that persistent Residual, semantic graphs or more state fields are needed.
