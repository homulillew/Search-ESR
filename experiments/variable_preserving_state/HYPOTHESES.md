# Mechanism hypotheses

H1: Requiring fully concrete Claims for unresolved variables can induce unsupported opponent, date, title and number bindings. H2: `open` status alone does not neutralize those bindings as future control signals. H3: explicit `unknown` slots can preserve coverage while reducing premature specificity. H4: query speculation may be transient, but persistent known bindings require question, observed evidence or explicit provisional hypothesis provenance.

The tested chain is explicit unknown → less unsupported binding → less confirmatory query bias → safe evidence-backed binding. Later edges are not inferred from an earlier passing stage.
