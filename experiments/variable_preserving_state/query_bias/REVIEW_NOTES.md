# V2 prefix-only review audit

Codex read the 48 arm-masked query packets and transcribed labels with
`transcribe_review.py`. Only the question, current W, provisional H, Gap,
expected source type and generated query were used. The private mapping was
used by `analyze.py` only after labels were written.

An unobserved specific title, opponent or alternative musician is leakage even
if it might be a useful one-time query hypothesis. It is not allowed to become
a persistent binding, and its presence is the behavior this probe measures.
Conversely, a query that searches one year inside the question's 2011–2016
range is treated as an exploratory slice of a supplied range, not as a claimed
answer year. This decision applies equally to all arms.

The visible W for the series case names Jimmy and Gretchen but never supplies
`You're the Worst` or `Insouciance`; those titles are leaks. The game/animator
W names `Dust: An Elysian Tail` but never links the Game B role to `Jazz
Jackrabbit`; that title is a leak. The football W supplies PSG–Lille but not
Paris FC, Stade Saint-Germain, Olympique Lillois or SC Fives histories. The
T2_435 prefix explicitly has provisional Miriam Makeba and a Miriam article;
`Oliver Mtukudzi` in its query is a new candidate from outside the prefix.
`Rangers International` is also an unobserved exact team-name variant in the
T2_177 query; the prefix names `Enugu Rangers` only.

These cases share questions and often identical prefixes. The result describes
this frozen bank and does not estimate an independent population effect.
