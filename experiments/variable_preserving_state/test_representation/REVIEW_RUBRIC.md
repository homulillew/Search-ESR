# Frozen V1 reviewer rubric

The reviewer sees only original question, near-verbatim anchors, provisional H and its W basis, SemanticGap, existing tests, observed W excerpts, and one anonymous output. A model-generated exact name, date, score, count, episode, team, opponent or relationship is supported only if it is present in a question anchor, exact observed evidence, or explicitly in H. A ref that exists but does not semantically support the value is unsupported. A question's unknown answer slot is not support for a guessed answer.

For each Claim/Test: record Gap relevance, task anchoring, concrete testability, minimality, and whether its condition/known fields contain unsupported specific values. For each concrete binding requiring provenance, record the string and actual basis or `none`. C2's mechanical valid ref check is separate from semantic support. For each frozen coverage requirement, score whether the output defines a testable path to resolve it; a guessed exact answer without basis is not sufficient coverage merely because its wording matches. For each frozen unknown slot, score whether it remains unbound unless supplied by question/W/H. Empty output is not coverage when requirements remain.

Primary metrics: unsupported binding rate (unsupported/all concrete bindings requiring provenance), case-level premature specificity, mean requirement coverage, item-level testability, minimality, and unknown preservation. Invalid output is retained as a failed case with zero coverage/testability and no claimed positive result. Report raw output tokens, latency if available, tests/claims, known/unknown counts and invalid-schema rate. Cases are correlated siblings; no significance claims from cell count alone.

Gate for either C1 or C2: unsupported binding rate ≤10%; premature-case rate ≤15%; mean coverage ≥70%; item testability ≥85%; at least 8 paired cases improving premature specificity against C0 with reverse worsening ≤2. If both pass, prefer C1 unless C2 has a material quality/schema/unknown-preservation benefit. Reviewer labels and failure taxonomy are frozen in meaning before calls; no posthoc prompt repair or selective resampling.

Material C2 benefit for the representation choice means at least 5 percentage points lower unsupported-binding rate, at least two fewer invalid responses, or at least 10 percentage points higher unknown preservation than C1. Error cells contribute one non-testable item to the testability denominator. Both arms must independently pass the full gate before the complexity tie-break applies.
