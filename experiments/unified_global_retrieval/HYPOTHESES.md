# Hypotheses

- H1: Pure full-corpus search can recover previously observed or discovered sufficient documents from a new Gap query without historical source hints.
- H2: The same search can discover newly required documents despite related old documents.
- H3: When a sufficient document is found, unchanged Find can recover useful evidence within one or two document inspections.
- H4: A soft history prior is valuable only if full-corpus recall of old sufficient documents fails while restricted-corpus recall succeeds, and must preserve new-source discovery.

The experiment is diagnostic. Cells sharing qids or target documents are correlated; no p-value or population claim is planned.
