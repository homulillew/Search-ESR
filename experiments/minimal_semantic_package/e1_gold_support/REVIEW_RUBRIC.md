# E1 content review rubric

This rubric is frozen before E1V. Gold packages and support/witness references
are immutable. Primary metrics are mechanically scored; review explains the
observed behavior and records disagreements rather than relabeling Gold.

Reviewers may see selected source target/context units, supplied Claims, content
JSON outputs, and frozen reference reasons. Provider reasoning is excluded.
Use a single task-familiar reviewer disclosure. If arm/replicate identifiers
are masked for diagnostic review, do not claim independent reviewers or perfect
blinding. All duplicate requests remain separate outcome slots.

For each completed chain, record:

- Whether the asserted support witness contains a frozen sufficient subset.
- Whether uncovered IDs point to actual target units, and whether their material
  content is really unsupported by the Claims actually available to that call.
- Verifier OPEN versus Auditor OPEN versus transport/schema failure.
- Genuine audit rescue versus rejection of a positive versus audit failure.
- Missing governing relation, comparison operand, qualified predicate,
  referent/source binding, or a reference-policy ambiguity.
- Whether a context unit was treated as an additional target. Unknown/context
  IDs already fail schema; valid target IDs can still hide semantic overreach.

No inference from hidden reasoning about why a model selected an ID. If content
JSON does not explain the cause, state that the cause is not identifiable from
the output. Do not attribute every false OPEN to sibling expansion when the
sibling never appeared in the verifier input.

Required cases: Euler, book-only/book+article, actual clinical/general SPS/FOP,
Ding/Kwon, DLC local mechanics/nation qualifier, championship membership,
memo/letter date, teammates, alma-mater/building. Report retained local positives
as well as rejected negatives. Keep ambiguous references visible and use
exclusion only as a descriptive sensitivity analysis.

Reuse historical Q0/Q1 without rerunning them, but disclose the changed target
contract, one changed label, extra auditor call and cited-witness scoring unit.
No causal claim that any performance difference isolates just segmentation.
