## Twelve design decisions

1. **Why v3 stopped.** Its explicit gate required complete schema enforcement, including array bounds and root unions. Thirteen diagnostics found an actual satisfiable strict-array violation, an impossible-schema negative-control failure, and rejected Actor representations. Admission/G4/G5 were never run. These do not establish that ordinary production JSON is unusable.
2. **Why not continue conformance work.** The new task assigns limited structural duties to transport and restores deterministic Harness control checks. One production schema implementation and one 24-request canary suffice; failure selects JSON-mode fallback, not another capability campaign.
3. **Transport duties.** JSON syntax, object keys, required fields, primitive types, enum, closed nested Search/Find/Open branches. Actor root is an object; actions remains an array with nested anyOf. No server minItems/maxItems. Same DeepSeek account, model, default thinking and sampling behavior.
4. **Harness duties.** Existing exact validator enforces action/Claim count, STOP/ACT and hypothesis consistency, registry membership, independent actions and budget. Semantic support/relevance/closure are separately reviewed offline; a schema-valid output is not automatically true or useful. No repair, retry or best-of.
5. **Natural arrays.** Preserve internal actions[] and claims_to_add[]; fixed slots would change the representation being studied and are expressly excluded.
6. **Ephemeral Gap.** The exact producing Actor gap conditions only that batch's Observation updates. It is not evidence and is not written into Claims. Only L0 retains its existing cached prior focus; L1/L2 do not acquire a persistent Gap field.
7. **Historical basis.** Read the required v3 audit/report/metrics, v2 conclusion/errata/G2–G5 reports/execution notes/prompts/adaptive runner, and both earlier admission studies. Observation-only F1 yielded 67/110 irrelevant Findings; Gap reduced this to 1/46, Gap+Claims to 0/38 with 29/32 required-atom recall (one stricter audit overreach). Live F3 still had missed facts and temporal binding errors, both arms 1/6 closure. Minimal Reader had 53/55 source support but only 47/55 support+relevance+novelty; source verification passed six irrelevant facts. v2 G5 had 503/504 source support yet 369/504 incidental admissions. Removing persistent Gap also removed Current Gap from update_view, restoring a known relevance failure. Existing Claims remain essential for novelty control. This run tests transfer to authentic online observations, not the abstract importance of relevance.
8. **Why Uc.** U0 is archived free-generation/no-Gap; Uc uses byte-identical v2 instruction and context with the selected new transport. U1 uses the same transport plus the supplied admission semantics and exact Current Gap. U1 vs Uc is primary; it estimates the admission package, not Gap alone isolated from instruction changes. Uc covers the full bank. U0 comparisons remain historical/stochastic references.
9. **Bank provenance.** Recover each v2 G5 update from its cell, round and wave; join the producing decision at that exact round; preserve actor output/request hash, source/window provenance, exact pre-state and Observation. All windows from both actions share that gap. Select deterministically using existing labels and fixed hash order, targeting six per qid without duplicates or fabrication. Freeze prefix-only useful atoms and scope before any replay output is available. Future states and gold answers cannot supply atoms.
10. **Frozen variables.** Preserve provider/model/account, all retrieval/backend/corpus/index/window semantics, Workspace/D/W, Q and persistent Claims/Hypothesis schema, max two Claims and actions, original G4 transitions and G5 ten qids/three decisions, batch-boundary L2 review, original closure/source-pool/Progress rubrics and q435 strict sensitivity. All tracked historical artifacts protected by byte hashes. Only new v3.1 files may change.
11. **Admission gate.** Require paired reduction of irrelevant/incidental admission against Uc without material loss of source support, useful-atom recall, scope, hypothesis control or no-change correctness. Report claim-level and qid-cluster descriptive results, not 60 independent questions. Empty output cannot pass by itself. G4 then tests online–oracle distance; G5 follows only without serious integrity failures. Do not predeclare a winning controller.
12. **Stops and bounded discretion.** API inability to return parseable JSON or authentication failure stops dependent live work. Admission failure stops confirmatory G4/G5. The user's explicit discretion permits a separately named, pre-frozen exploratory remedy within the same admission design, with no new persistent fields or provider probing; initial failures remain untouched. Do not lower the original gate after seeing outputs or silently substitute exploratory results. Document the observed failure and proposed remedy before exploratory calls; if no defensible narrow remedy exists, report that boundary.

## Interpretation fixed before data

Cleaner State with similar controllers favors simplicity (L1), not an equivalence claim. Fewer L2 premature stops without resolution/progress gain supports stopping value. Only L1≈L2>L0 supports harmful cached focus; equal/better L0 refutes that strong claim here. Common gains over v2 first implicate shared admission/transport changes. Persistent low resolution directs diagnosis to observed candidate/action/source failures, without expanding state schema. Preserve raw failures, planned denominators, actual cache usage and unknown cost.

## Review limitations

Historical strata are outcome-informed diagnostic sampling, not population sampling. Same qid packets correlate. Single reviewer knows historical studies; arm masking can reduce but cannot eliminate bias. Admissible atoms come exclusively from current Observation plus pre-state relevance, never future trajectories. Counterfactual post-state growth is local replay, not a rollout prediction.
