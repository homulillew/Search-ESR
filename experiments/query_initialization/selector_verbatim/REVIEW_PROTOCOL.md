# Selector → 原文检索：预注册审阅协议

本轮只检验自动选材的价值。固定二十道本地既有实验与报告未标记使用过的问题，随机种子 20260923。样本由 `prepare.py` 一次生成，来源与排除记录见 `selection_lock.json`；不声称训练数据未见或全局未见。锁定后不因题难、长度、返回结果或空选择换题。API 请求前还需冻结本协议、Selector prompt、运行实现和配置。

## 对照与执行

每题完整原题原文检索一次，自动 Selector 两次，总计最多六十次 Search、四十次初始模型请求。确定性的整题对照不重复伪造独立样本。此前六道人工固定 packet 仅作开发诊断，不增加为本轮对照组。

Selector 只选择当前原题的局部片段指针；运行时提取精确原文，保留顺序与片段边界并规范空白。不生成新的 query 表达，不添加相邻句，不按检索结果修复选择。最多一次格式修复，不把空选择、超预算或调用失败静默改成全文检索。所有失败保留在四十次选择分母内。API 请求不含 gold、历史答案或逐题人工建议。

统一模型 qwen3.7-flash、thinking=false、max_tokens=1536、timeout=120、SDK retries=0；使用固定现有 Search/Open 节点，top-k=6、每个初始窗口 400 tokens。查询上限为 1024 个本地 embedding tokens，计入 prefix 与特殊 token。并发仅改变调度，不改变每次独立输入；索引、检索参数、窗口策略保持一致。真实 API、检索及观察的调度与资源策略须写入运行 manifest。

## 工程与选材验收

1. 所有发出的 query 必须能由记录的原文确定性重建，片段边界、来源版本、窗口和账本审计全部通过。不得静默截断、引入事实或隐藏 fallback。
2. 首次合法选择至少 38/40；最多一次格式修复后 40/40 均形成有效、非空、预算内的检索输入。未达到即明确报告未过该阶段门槛，不临时放宽。
3. 至少 36/40 packet 可独立理解其搜索目的，主体、指代和采用的关键时间限定有足够上下文。严重误导性拼接逐条列出，即使总比例过线也不抵消此类风险。
4. 逐次记录选取片段数/总片段数、原文字符和 token 保留率、全选、空选、超预算、指代/主体/时间上下文缺失，以及重复间差异。全选不自动判错，遗漏复杂条件也不推定模型“逃避”。

原文单元是位置而不是语义事实；选择多段可能引入误导性并置。审阅者检查完整原题与实际 packet，不只检查合法编号。不同但合理的入口都可通过。

## 检索效用：先写定义，再看返回

所有二十题都必须覆盖审阅。按题汇集三次尝试 top-6 的去重来源，最多十八篇；从所有实际返回窗口开始审阅。窗口之外的原文只用于判断来源是否值得继续阅读，记录所查区间，不计为本次模型已见证据。范围固定为返回池，不扩充在线搜索或用答案反向捞取文档。

审阅分为两个维度：

- 所选入口/题内关系相关性：来源是否明确对应题内采用的某个事实组合，而非仅有主题词重合。
- 对完整原题的研究价值：它是否提供可溯源的中间实体、关系或一个有具体依据值得 Open 的来源；不能仅因满足 Selector 自己选的容易关键词就算成功。

每个题—文档记录以下状态及原文依据：

- `confirmed_useful_source`：有明确原文支持与原题关系相连的下一步阅读，或已提供有用中间事实。最终实体身份不必确定，候选相关性和局部事实要明确区分。
- `confirmed_visible_evidence`：该次实际窗口已经展示上述新依据。其他尝试或全文读到的段落不能借给此窗口。
- `plausible_unconfirmed`：可能相关，但当前审阅不能确认关系；不计确认正例。
- `no_confirmed_utility`：没有确认的研究价值；不宣称全文绝对无关。

每个确认正例记录原文摘录/区间、它支持什么、与原题哪部分相关、允许什么下一步行动。无需最终答案正确；“模型能写出下一问题”、主题词或裸候选名称均不足以独立成立。

既有 qrels 不覆盖新题；这是事后产生的、范围受限的来源标注，不称为完整 recall，不把未审阅当负例。不使用 LLM judge 或声称双盲；可先按 qid/docid 去重审阅，后映射 arm，但审阅者可能接触 query，须如实披露。所有二十题都要给出已确认/未确认/审阅不足状态；不足不能包装为零收益。

## 配对汇总与采用条件

来源命中和窗口依据可见分别统计，不合并。每题全文对照值为 0/1；Selector 两次分别记录，汇总每题均值以及是否两次都成功。报告逐题胜/平/负与全部失败分母，不能只报告任一次成功的 best-of-two，也不能把四十次当四十道独立题。

Selector 的题均确认有用来源率和题均可见依据率均不得低于全文对照。采用它还需要至少一题在全文未获相应价值时 Selector 两次均取得该价值，且对应总指标有净提升；纯持平、只靠单次偶然成功或只缩短 query 不足以增加默认模型调用。严重语义问题和实质性重复退化必须单列审阅，数值过线不等于自动推广。

上述是本阶段二十题的工程门槛，不是统计显著性或广泛泛化证明。输出成本、延迟、修复和审阅不确定性；若 Selector 没有稳定增益，保留全文原文基线并继续后续观察管理节点，而不是为了过线追加提示词补丁。
