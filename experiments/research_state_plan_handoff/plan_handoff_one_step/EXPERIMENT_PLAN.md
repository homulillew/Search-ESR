# P1: frozen broad plan handoff, one step

H0 is the completed DeepSeek M2 response for all 13 frozen checkpoints, with
no resampling. H1 appends a descriptive control card made from each exact
historical DeepSeek M1 field value, then requests one actor response with the
same Search/Find/Open schema. No tool executes. One sample per checkpoint;
zero SDK retries; every response, validation failure, and API error remains.

The primary outcome is whether any call in a document-plan batch is Find,
reported alongside first-call Find, exact target agreement, mixed-batch
composition, and Search despite a non-corpus plan. The primary paired
denominator is the four historical DeepSeek document plans; all 13 remain in
the table. Scope compliance and target/source utility are separate.
