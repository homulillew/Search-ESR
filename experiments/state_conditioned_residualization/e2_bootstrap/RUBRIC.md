# E2/E2B frozen semantic review

Single familiar reviewer; primary opportunity review sees Q, fixed parent, current Claims, query and only returned top-five visible title/preview windows. It does not import full source contents or future Claims into a primary label. Mask arm and case identifiers in review packets; query wording may reveal the arm. Archive rationales and supporting refs for all gains. Commit judgments before aggregate. No Writer runs: claim admission is not measured, only an independently reviewed opportunity.

NewMaterial: a new explicitly supported parent-relevant fact which could be a Verified Claim (including a useful binding), not completion of all parent constraints. Binding: a new concrete entity/event/document/relation anchor that reduces parent uncertainty. Direct: new evidence about a parent predicate/constraint, even a partial predicate; bridge: an identified intermediate anchor with a supported route to testing the parent, not mere topical similarity. These may overlap within one query. NoGain means neither material nor binding; unavailable slots are failures and are not real NoGain for escalation. Metrics retain all planned slots. Explicitly distinguish potential candidate from established target.

Do not count an arbitrary member of a vast generic topic as progress. A source must share a discriminative parent facet, or establish a specific entity/date/relation relevant to reducing the current uncertainty. One conjunction facet can qualify even though other prerequisites remain. Current Claim repetition alone does not count. Direct and bridge evidence must be supported in visible raw text. Repeated-doc fraction uses returned slots as denominator and current-prefix corpus IDs; expose overlap across paired arms separately. Repeated documents can contain new evidence.

Query drift: incompatible entity/role/relation/time substitution or an objective outside parent scope, not every missing search keyword. Commitment: inserting an unsupported concrete candidate or asserting the identity/binding of a provisional candidate. Query-generation fidelity uses supplied objective as authority per TASK33; Q provides context but does not license adding an absent concrete name/date.

E2B only actual P1 NoGain with both no material and no binding, accessible source unchanged, and an untried source-anchored parent facet. One extra objective and one extra query; schema failures block dependents, no repair. Oracle diagnostics remain separate, frozen before execution. No evidence-recognition failure can be claimed without an observed failed recognizer; this experiment has no Writer.
