# Minimal Need → Multi-Query, protocol v1

## Boundary and authorization

Persistent semantics: original Q, source-supported Claims, provisional H only. Need and any action batch are regenerated after real observations. Provenance, source addresses, attempts and traces are mechanical records. No new semantic state, graph, planner, verifier, lifecycle, tool mask or backend change.

Task §35 requires explicit paid-call authorization in the current task. None accompanied the pasted task. Complete E0 and E1 preparation, then stop at PREPARED_FOR_REAL_RUN. No connectivity probe, remote model listing or model canary. Existing credentials are not authorization. Skill: academic-research-suite experiment workflow is used inline for provenance, preregistration and integrity; the stop comes from the user task.

## E0: offline rubric correction

Select exactly the five primary W entries of the old B5 confirmation (not Delta projections). Review QCH plus historical Need, preserving old labels/reasons. Separate resolution judgments from constituent facts. Record uncertainty and alternative readings. No source discovery, model call or retrieval. The reclassification is not a changed historical score or a measured multi-query benefit.

## E1 development

18 natural, previously exposed states: all four old P, one A, five W; eight old strict-valid controls selected deterministically, one per qid, earliest state, ascending numeric qid. All selected QCH bytes and user messages match historical inputs. H remains provisional even when assertively worded. Audit Claims against archived current observations and source-relative support reviews. H provenance points to actual U1 state history. No manually written Claims/H, future evidence or historical Need in payload.

Four arms, one response per state, 72 calls, horizon one, no tools or Writer. B0 is the exact B5 prompt and historical payload. B1 appends only the task's three premise paragraphs; B2 appends only its three coherence paragraphs; B3 appends both in that order. The constant `decision: research` envelope is retained in every arm to keep B0 byte-identical; `need` is the sole variable semantic output. There is no STOP output. No examples or hidden case-specific hints are added.

B0 is sampled concurrently, not borrowed from failure-selected historical outputs: selection creates regression-to-mean risk. Historical responses support selection and E0 only. Arms use identical QCH, model, JSON mode, temperature 0, omitted max_tokens and zero retries. Deterministic schedule orders states by SHA-256 with rotating arm order. Up to eight independent HTTP calls overlap; scheduling order does not guarantee server order. Cache differences are reported, not forcibly equalized. The first scheduled formal call also serves as the credential check, is retained and is never rerun; after success the rest can run concurrently. A typed 401/403 stops new sends, retaining blocked cells and already in-flight calls.

Review follows RUBRIC.json. Arm-masked packets omit old labels and reasons. All dimensions and reasons must be reviewed; a parser never claims semantic validity. Primary ITT denominators are the whole schedule. Missing/auth-blocked/interrupted/schema/length/timeout cells remain failures. P/A/W are observed-content diagnostics; missing outputs remain semantically unknown. Show No-H, paired changes, per-qid counts, conditional results and token accounting. Never treat sibling states as independent questions or use a significance gate.

Development thresholds operationalize §16's directional patterns before calls. If a mechanism is not separable, stop and analyze floor effects and instruction conflict before any fresh stage. At most one bounded, versioned revision; no automatic prompt sweep or sample replacement.

The exclusion registry is conservatively collected from tracked experiment qid fields/paths and prior exclusions; it must be refreshed and manually checked at the future freeze, including then-current untracked/local materials. No claim of freshness rests solely on a filename scan.

Freeze question-only qid selection and acquisition budget before collecting; then hash QCH, audit Claim support and H origin, freeze all evaluation inputs and commit before Need calls. Unfilled strata or inadequate natural states block confirmation. Required strata are candidate/relation uncertainty, downstream attribute temptation, identity uncertainty, No-H, coherent multi-facet, independent broad objectives, and strong H with missing constraints.

Fresh arms are concurrent B0 and frozen B3, one response/state (60–80 calls). Conjunctive gate: B3 strict ≥80%; conservative P+A count/N ≤5%; W/N ≤10%; strict improvement ≥15 pp. Use integers/exact ratios, report No-H separately. A FAIL stops E2/E3/E4. Acquisition and fresh calls are not authorized or scheduled by this preparation.

## E2: reviewed Need → Search expressions

Gate: E1 fresh PASS, then separately freeze 20–30 reviewer-approved Needs split between Type S and M. Inputs to query generation are only Need; no model-generated Need input, QCH, support audit or gold. Q0 one query top6; Q1 one to three independent queries each top2. Six display slots are RESERVED per arm: unused Q1 slots remain empty when fewer than three queries are emitted, with no refill, dedup compensation or reranking. Thus Q1 gets no more retrieval/display allowance; report actual usage, underfill and the exactly-three-query sensitivity. This interprets the task's simultaneous 'at most three' and '3×top2' requirements without forcing invented queries.

Same frozen Search backend and per-window 400-token title/body allowance; six slots ≤2400 tokens. More retrieval invocations still cost more computation and must be reported separately from equal display allowance. Freeze exact backend/version/assets at E2, with no modification now. Queries generated before any results; independent retrieval calls may run in parallel when the unchanged backend permits it. Do not claim GPU computation costs are equal.

Primary unit is a Need: observed evidence sufficient to support/refute its full coherent judgment within the budget. Partial coverage is secondary, not primary success. Review every returned window for exact subject/relation/scope, each facet's evidence, and cross-source joins. Deduplicate useful sources by document identity; retain duplicated slots in denominator. Record semantic drift (Need-level any query drift), assumptions, redundancy, overlap, coverage, tokens/cache, retrieval invocations and wall time.

Proposed operational thresholds, to be frozen with a qualified bank before any E2 call: Type M useful-evidence difference ≥15 pp; Q1 drift rate no higher than Q0; Type S useful-evidence decline ≤5 pp. Include ITT and common-completed sensitivity; no failure deletion. Failed gate removes fan-out from the candidate design. Query prompts are prepared only; no E2 bank or runtime invocation exists yet.

Only positive Search-only evidence opens a separately frozen ActionBatch test. Input Need + mechanical directory/attempts only; 1..3 Search/Find/Open actions, independent at generation time. A result-dependent action waits for Observation→Writer→new Belief→new Need. All tools remain available.

## E3 and E4

E3 requires E1/E2 PASS and a new adequately diverse natural near-closure bank. Freeze bank sufficiency and numeric reactivation/closure gates before calls; these gates are not retroactively inferred from historical loose resolved labels. ACT needs one useful gap; STOP needs all material constraints plus the final requested relation supported/strictly entailed by Claims. H supplies no coverage. This preparation does not manufacture resolved controls or predeclare E3 ready.

E4 requires all prior gates PASS: 10–15 completely held-out qids, separately frozen call/horizon budgets, full specified metrics, exact observations, U1 updates and strict closure. No runner path automatically skips a gate. E2–E4 have design documents only, not fake runs or empty success metrics.

## Freeze, failure and cost

Before any real stage: protocol, hypotheses, bank, Claim/H provenance, prompts, rubric, configuration, schema and schedule are hashed and committed. The execution records exact HEAD and manifest digest before the first send. Exclusive output paths prevent overwrite/resume; no failure retry. Code/input changes require a new version/freeze. Auth short-circuit retains all planned denominators. An interrupted attempted cell has unknown usage, never zero inferred cost. Missing or inconsistent usage is explicitly incomplete accounting. Output includes reasoning; do not add reasoning again. Cache = sum(hit)/sum(hit+miss), with coverage and hit+miss/input consistency. No unverified currency quote.

Historical tracked experiment hashes are checked before and after preparation. User's untracked research directories are outside this task and left untouched. Single-reviewer judgments, two repeated DLC states and sampled-provider variability limit generalization.
