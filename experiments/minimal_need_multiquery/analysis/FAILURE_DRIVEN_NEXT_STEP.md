# Failure-driven next experiment — design only, not executed

The current task's sole bounded development revision is exhausted. There are no requests, fresh labels, success estimates or automatic execution behind this document.

## Narrow question

Can an **ephemeral explicit premise check** prevent asking an attribute of an unverified candidate event? Concrete observed failures are donor→gift→building university, author→article→title, artist→interview→song and memorandum-date→letter-date binding.

An independent future experiment could compare the current baseline with a transient two-call computation: identify one proposed subject/event and enumerate only the facts needed to ask its attribute; bind each fact to Q or a C statement; if a required event/role is unsupported, derive an existence test or a discovery Need instead. H may nominate the subject but cannot fill an evidence anchor. Return only the final natural-language Need to the harness; discard the intermediate structure after the decision and retain it only in private audit trace. This would be a changed computation policy, not additional persistent semantic state.

Separate actor/model compute from state effects: preregister call/token accounting, retain failures from either step, and use a concurrent comparison with a suitable compute control. Do not certify the intermediate list merely because it exists: unsupported or misbound anchors are themselves errors. Freeze cases and semantic labels before calls; reserve untouched qids for later confirmation. The present development qids cannot become fresh again.

The six W failures also motivate a distinct, tiny ephemeral decomposition diagnostic. Do not combine both new mechanisms in a single initial causal claim. Test P/A first; review W, stale selection and execution length as possible regressions. Neither idea licenses a persistent frontier, global requirement map, dependency graph or STOP rule.

The reports' negative result is already robust to forgiving every A/W label. More semantic relabeling or another unregistered prompt sweep is not a substitute for a separately designed experiment.
